# Mergington High School Activities

A website application that allows students to view extracurricular activities and teachers to manage student sign-ups.

## Features

- View all available extracurricular activities in **Card View** or **Calendar View**
- Search activities by name
- Filter activities by category (Sports, Arts, Academic, Community, Technology)
- Filter activities by day of the week
- Filter activities by time (Before School, After School, Weekend)
- Teacher login for authenticated access
- Teachers can register and unregister students for activities
- Activity data is persisted in a MongoDB database
